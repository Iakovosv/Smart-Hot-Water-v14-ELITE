# Smart-Hot-Water-v14-ELITE
Ο GSW: Smart Hot Water v22 ELITE είναι ένα Home Assistant Blueprint για έξυπνο έλεγχο θερμοσίφωνα / ηλιακού, σχεδιασμένο για ελληνικές συνθήκες (κρύα/ήπια κλίματα, ηλιακός, πολλαπλοί χρήστες κτλ.).

Κύριες δυνατότητες:

Έλεγχος θερμοκρασίας νερού: Σβήνει αυτόματα όταν φτάσει τη θερμοκρασία στόχο.
Λογική Κρύο / Ήπιο κλίμα: Αυτόματη επιλογή στόχου θερμοκρασίας και μέγιστου χρόνου με βάση την εξωτερική θερμοκρασία.
Μέγιστος χρόνος λειτουργίας (safety): Ξεχωριστά όρια για κρύο και ήπιο καιρό.
Πολλαπλά προγράμματα (schedules): Έως 3 ώρες/προγράμματα με δικό τους στόχο θερμοκρασίας ή auto.
Έλεγχος παρουσίας χρηστών (presence):
Ο User 1 είναι υποχρεωτικός.
Ο User 2 είναι προαιρετικός.
Αν κανένας από τους ορισμένους χρήστες δεν βρίσκεται σε κάποια από τις επιλεγμένες ζώνες του, ο θερμοσίφωνας δεν ανάβει.
Defrost για ηλιακό:
Λειτουργεί μόνο σε συγκεκριμένο χρονικό παράθυρο (π.χ. 03:00–05:00).
Ανάβει μόνο αν το νερό και η εξωτερική θερμοκρασία είναι κάτω από τα defrost όρια.
Έλεγχος water_temperature_check:
Αν είναι ON, μπλοκάρει κάθε θέρμανση.
Παράκαμψη θέρμανσης όταν το νερό είναι ήδη ζεστό:
Αν η τρέχουσα θερμοκρασία νερού είναι ≥ στόχος, δεν ανάβει.

Προαπαιτούμενα
Χρειάζεσαι:

Ένα switch για τον θερμοσίφωνα (boiler_switch).
Έναν αισθητήρα θερμοκρασίας νερού (water_temp_sensor).
Έναν αισθητήρα εξωτερικής θερμοκρασίας (outdoor_temp_sensor).
Ένα input_boolean για ενεργοποίηση/απενεργοποίηση του συνολικού αυτοματισμού:
input_boolean.gsw_smart_hotwater_enable
Ένα input_boolean για μπλοκάρισμα θέρμανσης από manual έλεγχο:
π.χ. input_boolean.water_temperature_check
Τουλάχιστον 1 χρήστη τύπου person και αντίστοιχες ζώνες τύπου zone.
Πως δουλεύει
Trigger
Τρέχει κάθε 5 λεπτά (time_pattern trigger).
Γενικός έλεγχος
Αν το input_boolean.gsw_smart_hotwater_enable είναι off, δεν κάνει τίποτα.
Σε κάθε εκτέλεση:
Υπολογίζει στόχο θερμοκρασίας (ανά schedule και συνθήκες).
Ελέγχει παρουσία χρηστών στις επιλεγμένες ζώνες.
Ελέγχει αν επιτρέπεται θέρμανση (water_temperature_check, ήδη ζεστό νερό).
Παρουσία χρηστών (Presence Logic)
User 1:
Υποχρεωτικός.
Επιλέγεις μία ή περισσότερες ζώνες (π.χ. Home, Village, Parents κ.λπ.).
User 2:
Προαιρετικός.
Αν δεν δοθεί, απλά αγνοείται.
Για να ανάψει ο θερμοσίφωνας:
Πρέπει τουλάχιστον ένας χρήστης (User 1 ή/και User 2) να βρίσκεται σε κάποια από τις ζώνες που έχεις ορίσει.
Schedules (Προγράμματα)
Υπάρχουν 3 προγράμματα:

Για κάθε schedule ορίζεις:
Time (ώρα).
Target Temp:
Αν είναι 0, τότε ο στόχος βγαίνει αυτόματα:
Αν η εξωτερική θερμοκρασία < cold_threshold → χρήση target_temp_cold.
Αλλιώς → χρήση target_temp_warm.
Αν είναι > 0, χρησιμοποιείται αυτή η θερμοκρασία.
Στην ώρα του schedule:
Ελέγχει:
Αν υπάρχει παρουσία (User 1/2 στις ζώνες τους).
Αν το νερό είναι κάτω από τον στόχο.
Αν το water_temperature_check είναι off.
Αν όλα είναι ΟΚ:
Ανάβει τον θερμοσίφωνα.
Περιμένει μέχρι η θερμοκρασία νερού να φτάσει στον στόχο ή να λήξει ο max_time_cold / max_time_warm.
Σβήνει τον θερμοσίφωνα.
Defrost Λογική
Αν είναι ενεργό το defrost_enable:
Ελέγχει χρονικό παράθυρο (defrost_start_time – defrost_end_time).
Ελέγχει:
Αν υπάρχει παρουσία (ίδια λογική με τα schedules).
Αν θερμοκρασία νερού ≤ defrost_water_temp.
Αν εξωτερική θερμοκρασία ≤ defrost_outdoor_temp.
Αν water_temperature_check είναι off.
Αν όλα ισχύουν:
Ανάβει τον θερμοσίφωνα.
Τον κρατάει ανοιχτό για defrost_check_interval λεπτά.
Τον σβήνει.
Ρυθμίσεις ασφαλείας
Μέγιστος χρόνος:
Για κρύο καιρό: max_time_cold.
Για ήπιο καιρό: max_time_warm.
Threshold Κρύου:
Αν η εξωτερική θερμοκρασία < cold_threshold, θεωρείται “κρύο”.
water_temperature_check:
Αν είναι ON, δεν θα ανάψει ποτέ, ανεξαρτήτως προγράμματος ή defrost.
Οδηγίες εγκατάστασης
Αντέγραψε το YAML του blueprint στο config/blueprints/automation/ (ή από το UI → Blueprints → Import).
Κάνε Reload Automations από Settings → Devices & Services → Automations.
Δημιούργησε νέο automation από το blueprint:
Σύνδεσε το boiler_switch.
Επίλεξε τους αισθητήρες water_temp_sensor και outdoor_temp_sensor.
Επίλεξε τα input booleans (gsw_smart_hotwater_enable, water_temperature_check).
Ρύθμισε users και ζώνες.
Ρύθμισε schedules, θερμοκρασίες και defrost.
